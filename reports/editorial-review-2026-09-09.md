# Semiconductor Design Lab 개선 검토

기준일: 2026-09-09. 대상: semicon-circuit.tistory.com.

## 결론

반도체 개념, RTL 구현, 졸업 프로젝트가 연결되어 있다는 점이 이 블로그의 강점입니다. 기업 뉴스룸의 발행량을 따라가기보다 이미 쓴 글을 찾기 쉽고 순서대로 읽기 쉽게 만드는 편이 적합합니다. 무채색 디자인과 기존 글·사진을 보존하면서 홈의 진입점과 본문 접근성을 개선합니다.

## 구현 범위

### 홈

1. 최신 공개 글을 대표 화면에 배치. 작성일 기준이며 번호가 크더라도 과거 작성일이면 최신으로 취급하지 않음.
2. 기존 홈의 모식도를 재사용하고 전체가 보이도록 배치.
3. 대표 시작점: Systolic Array 구조(/113), UART 개념(/98), Full Custom 포트폴리오(/80). 공개 목록에서 빠지면 표시하지 않음. 인기도 순위가 아님.
4. Explore: 공개 글 제목·분류·태그·발췌 검색, 상위 주제 필터, 최신순/제목순 정렬, 6편씩 더 보기.
5. 검색 결과 없음·초기화·키보드 포커스·모바일 레이아웃 처리.
6. RSS는 티스토리 기본 피드 연결. 이메일 수집·외부 구독 서비스 추가 없음.
7. 검색어는 서버나 Analytics에 전송하지 않음. 홈의 실제 글 클릭만 기존 Analytics가 있는 경우 기존 internal_article_click 이벤트에 home_lead, home_start, home_archive 위치로 구분.
8. 사용자 요청에 따라 홈 배경을 오프화이트(#f6f6f4)·차콜(#181818)로 조정. 회로 도식은 흰 배경을 유지하며, 본문 페이지 배경과 원본 이미지 색상은 변경하지 않음.

### 글 화면

1. 목차와 시리즈 순서는 필요한 독자가 펼쳐 볼 수 있도록 접어서 표시.
2. 작성자가 만든 ‘핵심 요약’ 또는 ‘요약’ H2/H3, 또는 인용문의 첫 강조 제목이 있으면 AI 요약 중복 생략. 그 외 AI 요약은 펼침형으로 제공하고 AI 표시 유지.
3. 본문 바로 읽기, canonical 주소 복사, 본문 스크롤 진행률. 진행률은 실제 정독 여부를 뜻하지 않음.
4. 코드 도구가 생성된 블록에서 기존 스킨의 중복 복사 버튼만 숨김.
5. 추천·본문 메타의 예상 읽기 시간을 같은 공개 목록 값으로 통일.

### 데이터 품질과 보존

- 공개 본문이 있는 글만 목록에 포함. 비공개 글을 읽거나 발행하지 않음.
- 앞부분에 ‘이전 글’ 링크가 있어도 도입부 전체를 버리지 않도록 발췌 추출 개선.
- 이전 편 설명으로 시작하는 경우 ‘이번 글에서는’ 부분부터 표시.
- 긴 발췌는 단어 경계에서 자르고 말줄임 명시.
- 추출 규칙에 버전을 붙여 이전 결과가 영구 캐시되지 않도록 함.
- 원래 서버 렌더링 홈은 보존. 새 홈을 완성한 후에만 이전 홈을 숨김. 목록 다운로드 실패 시 기존 홈 사용.
- 공통 UI 변경으로 글 본문·원본 이미지·공개 여부·댓글·광고 설정·AI 답변 모델을 변경하지 않음. 별도 요청받은 /122의 첫 장식 이미지와 대표 이미지만 2D 블록도로 교체함. 본문과 논문 원본 그림 7개는 유지.
- 페이지 단위 생성형 AI 호출, 새 유료 서비스, 새 분석 서비스 추가 없음.

## 검증

자동 검사 통과: 공개 글 유효 URL·중복 제외, 전체 주제별 필터 합계, 영문 대소문자 검색, 다중 키워드, 빈 검색, 미래 글/과거 작성일 정렬, 스크롤 범위. 기존 100개 공개 글 내비게이션 검사, Python 11개, Worker 회귀 검사도 통과했습니다.

실제 스킨을 사용하는 로컬 브라우저에서 375px·1280px·1920px의 가로 넘침 없음, 라이트·다크, 검색·필터·정렬·더 보기·목차/시리즈 펼침·본문 이동·링크 복사 성공 안내를 확인했습니다. /124의 목차와 시리즈 영역 합계 높이는 약 434px에서 98px로 감소했습니다. /96의 AI 요약은 접힘형으로 표시됩니다. catalog 실패를 강제로 발생시킨 테스트에서도 기존 홈이 표시되었습니다.

## 추가하지 않은 것

- 개인 프로젝트의 검증 조건을 무시한 기사 자동 생성·무인 발행
- 타 사이트 기사/이미지 복제, 과장된 제목, 가짜 조회수·인기순·경력·평점
- 가입 팝업, 자동 다음 글 이동, 이메일 수집과 유료 분석 도구

## 다음 편집 작업

- /124의 ‘1. Transformer…’, ‘6. AI Accelerator…’, ‘정리’, ‘참고 자료’가 실제 H2가 아닌 본문/목록 안에 있어 목차에서 빠집니다. 원문 구조 문제이므로 이번 공통 UI에서 추정해 재작성하지 않습니다. 별도 글 편집에서 리스트 경계와 H2/H3를 교정해야 합니다.
- 이미지 ALT는 그림을 직접 확인해 설명하고 논문 결과나 제공되지 않은 정보를 추측하지 않습니다.
- 시리즈는 ‘개념 → 동작 과정 → 구현/검증 → 한계’로 연결하되 한 편의 대상 독자와 질문을 명확히 합니다.
- 향후 2~4주 동안 같은 기간·요일 조건으로 홈→글 클릭률, 세션당 조회수, 자연 검색 클릭을 비교합니다. 성장 효과는 아직 미측정입니다.
