# AI 어시스턴트 개선 검수 — 2026-09-09

## 범위

- 블로그 AI 패널의 질문 분류·출처·대화 제어·접근성 개선입니다.
- Worker 코드, AI 모델, 사용 한도, API Key, Cloudflare 요금제, 수집 항목·보존 기간은 변경하지 않았습니다.
- 글 본문·공개 상태·발행일은 변경하지 않았습니다. /124 편집기의 저장 전 수정본과 전체 글 내용 검수는 별도 승인 대기입니다.

## 수정

- 기술 질문 속 `몇 개`, `정리`, `추천`을 글 목록 명령으로 잘못 처리하던 규칙을 명시적인 글 명령으로 제한했습니다.
- 검색어에서 `한`, `의`, `글` 같은 음절을 무조건 삭제하지 않습니다. `한계 전압`, `의존성 분석`을 보존합니다.
- 검색 결과 없음 → 자동 AI 호출을 제거했습니다. 방문자가 `AI에 질문하기`를 선택할 수 있습니다.
- 현재 글 제목을 패널에 표시하고, 다른 페이지의 대화를 현재 글 질문에 무조건 섞지 않습니다.
- 질문은 기존 서버와 동일한 300자로 제한합니다. 현재 글 제목을 질문 앞에 붙여 질문 끝이 서버에서 잘리던 위험을 제거했습니다.
- 연속 Enter 중복 전송 방지, 한글 조합 Enter 유지, 응답 대기 중단, 새 대화를 제공합니다.
- 중단은 브라우저의 응답 대기 중단입니다. 이미 진행된 서버 처리·사용량을 취소하거나 환불한다고 표시하지 않습니다.
- 25초 시간 초과, HTTP 429/401/403, 잘못된 JSON, 비어 있는 응답을 복구하며 자동 재시도하지 않습니다.
- 출처 없는 서비스 안내는 다음 답변의 대화 맥락에 저장하지 않습니다.
- 출처는 알려진 공개 블로그 글 URL·ID만 링크하며, 원래 출처 번호를 유지하고 현재 목록 제목을 사용합니다.
- 문단·목록·Inline Code·Code Block을 구분하고 답변의 첫 문장을 먼저 보여줍니다.
- 기존 대화 복원 시 허용된 태그만 재구성합니다. 이벤트 속성·잘못된 URL은 제거합니다.
- 무채색 라이트·다크 패널, 닫힌 패널의 키보드 접근 차단, Escape 포커스 복구, 모바일 패널/입력 폭을 개선했습니다.
- 조회수 기반이 아니었던 `인기 글` 버튼은 `핵심 글`로 바꿨습니다. 학습 완료·글 개수 문구를 추가하지 않았습니다.

## 검증

- `tests/assistant.test.cjs`: 기술 질문 및 검색어 회귀, URL 검증, 출처 번호, 안전한 렌더링, 대화 길이 제한, 소스/배포 파일 일치, 기본 텍스트 대비 4.5:1 이상.
- 기존 editorial/navigation/Worker 테스트 통과.
- 실제 글 HTML을 사용한 로컬 미리보기에서 확인:
  - `PE가 몇 개 필요해?`, `KV Cache 구조 정리해줘` → AI 경로.
  - 현재 글 질문은 이전 대화·출처 ID 없이 현재 postId 전달.
  - 반복 Enter → 요청 하나, 마우스 전송·대기 중단 후 패널 유지 및 질문 복구.
  - HTTP 429, 잘못된 JSON, 출처 없는 서버 안내, 25초 시간 초과 후 입력 복구.
  - 존재하지 않는 키워드 검색 시 AI 요청 수 증가 없음.
  - 새 대화 후 UI 1개 안내만 남음.
  - 저장된 HTML의 img/onclick/javascript 링크 제거, 정상 버튼 텍스트 유지.
  - Escape → aria-hidden/inert 및 AI 버튼 포커스 복구.
  - 375×812, 812×375, 1280×900, 1920×1080에서 패널 화면 내 배치·가로 넘침 없음.
  - 모바일 다크·라이트 시각 검수, 긴 답변 첫 문장 노출 확인.
- 모든 답변 검증은 로컬 가짜 응답으로 수행했습니다. 실제 AI 모델 호출/피드백 전송은 하지 않았으므로 실제 답변 품질이 향상됐다고 단정하지 않습니다.
- 가상 키보드 열림은 visualViewport 대응 코드를 추가했지만 실제 iOS/Android 기기에서 직접 검증하지 않았습니다.
