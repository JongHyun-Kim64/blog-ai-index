# 홈 LATEST: 최신 공개 글 5편 슬라이드

## 적용 범위

- 기존 홈의 이미지·제목·요약 2열 배치, 무채색 테마, FEATURED 및 Explore 유지.
- 공개 catalog를 발행일 내림차순으로 정렬하고 중복/잘못된 URL을 제거한 최대 5편 표시. 현재 /124, /123, /122, /121, /120.
- 이전/다음 화살표, 5개 위치 버튼, `01 / 05` 표시. 마지막/첫 슬라이드 사이 버튼 순환.
- Native horizontal scroll + CSS Scroll Snap으로 모바일/트랙패드 넘김 지원. 별도 Slider 라이브러리·자동 재생·AI/API 호출 없음.
- 방향키·Home/End, 현재 슬라이드 상태 안내, 비활성 슬라이드의 탭 이동 제외, Reduced Motion 지원.
- 모든 슬라이드는 같은 높이의 Grid 행을 공유. 이미지 원본은 변경하지 않고 contain 유지. 첫 이미지만 eager/high priority, 나머지는 lazy.
- 새 JS/CSS 버전으로 함께 로드하며, 기존 head CSS도 새 버전 로딩을 기다린 뒤 홈 활성화.
- 글이 한 편이면 넘김 컨트롤 숨김. 목록 로딩 실패 시 기존 티스토리 홈 유지.

## 참고

[SK하이닉스 뉴스룸](https://news.skhynix.co.kr/)의 메인 5개 슬라이드·위치 선택 방식을 직접 확인했습니다. 이미지 위에 제목을 겹치는 방식이나 브랜드 색상, 자동 재생은 가져오지 않았습니다.

## 검증

- `tests/latest-carousel.test.cjs`: 최신 5개/정렬/중복·잘못된 URL 제외/새 글 반영/순환/이전·다음/위치 선택/키보드/포커스/가로 스크롤/Resize/Reduced Motion/1개·0개 처리 통과.
- 기존 editorial/navigation/visitor chart 회귀 테스트 및 skin/docs 미러 동일성 통과.
- 저장된 공개 티스토리 스킨으로 1280px, 375px, 1920px 확인. 가로 페이지 넘침 없음. 1920px의 5개 슬라이드 높이 모두 382px, 이미지 5개 정상 로드.
- 모바일 가로 스크롤 후 실제 /123 및 `02 / 05`로 동기화 확인. 버튼으로 3→4→5→1 순서 확인.
- 모바일 다크모드 및 데스크톱 키보드 End로 5번째 글 이동 확인. 화면 크기 변경 후 선택 글과 가로 위치 유지.
- 한 편인 경우 `01 / 01` 및 컨트롤 숨김, 목록 실패 시 원래 Featured 영역 표시 확인.
- 미리보기 서버는 `scripts/preview-latest.cjs`로 127.0.0.1:8772에만 바인딩하며 Analytics 및 AI 호출을 제거한 로컬 검증용입니다.
