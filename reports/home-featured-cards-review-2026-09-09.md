# 홈 대표 글 · 추천 카드 · 썸네일 통일

## 범위

- 홈의 LATEST 1개와 기존 레이아웃 유지. Start here 자리를 FEATURED로 변경.
- FEATURED는 실제 조회수 순위가 아닌 편집상 선정: UART 개념(/98), Buck Converter(/101), Full Custom IC 포트폴리오(/80). 주제 이름과 최신 공개 catalog 제목을 사용하며 공개 목록에서 빠진 글은 표시하지 않음.
- 게시글 추천 글과 인기 글을 동일한 텍스트 카드 구성·글꼴·구분선·간격으로 통일. 데스크톱 3열, 모바일 1열. 기존 티스토리 인기 목록의 순서를 보존하고 자기 글·중복·외부 URL 제외. 원래 인기 목록은 삭제하지 않고 새 카드가 만들어진 경우에만 숨김. 늦게 로딩되는 인기 목록에도 대응.
- 카테고리/검색/태그/아카이브 목록의 썸네일만 중앙 cover 확대 표시. 가장자리 일부가 잘릴 수 있음. 홈 상단 모식도 contain과 본문 이미지 원본·색상은 유지.
- 새로운 AI 호출, 유료 서비스, 추적 서비스는 추가하지 않음. 기존 Analytics가 있을 때만 기존 이벤트 방식으로 home_featured/article_popular 클릭 위치를 구분.

## 검증

- editorial/navigation 단위 테스트 통과. 공개 글 100개의 기존 추천·시리즈 테스트 유지.
- FEATURED의 3개 주제, 제목 변경 반영, 공개 목록 제외, 잘못된 URL을 검사.
- 인기 글의 원래 순서·정상 URL 정규화·자기 글/중복/외부 URL 제외·최신 catalog 제목을 검사.
- skin/docs JS·CSS 동일성 검사.
- 기존 티스토리 HTML을 사용하는 로컬 미리보기에서 홈 대표 글 3개, 추천 3개, 인기 6개 확인.
- 데스크톱 인기 카드 6개의 너비 약 257px·높이 약 203px 동일. 모바일 375px에서 1열, 가로 넘침 없음, 다크모드 제목 rgb(240,240,240).
- 카테고리 데스크톱/모바일에서 background-size:cover와 가로 넘침 없음 확인. 데스크톱 첫 사진 6개 16:10 비율 유지.
- 레이아웃 개선에 따른 클릭률/조회수 효과는 아직 측정하지 않음.

## 배포

로컬 수정 및 검수 완료. 원격 push와 티스토리 로더 갱신, 공개 페이지 확인은 진행 중.
